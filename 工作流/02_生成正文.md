# 工作流 02：独立生成正文初稿

## 前置条件

- 控制器调用本工作流前，原阶段必须为 `等待确认执行卡`，并已将当前阶段切换为 `正在生成正文`。
- 当前任务登记的本章资料包、正文最小包和场景执行卡必须存在且可读取；资料包只供控制器校验存在，不得传入正文生成任务。
- 当前任务中不得存在未解决的阻塞冲突。

当前阶段不是 `正在生成正文` 或其他条件不满足时停止，不猜测章节或文件。

## 上下文限制

正文生成阶段只允许读取：

- `工作区/第N章_正文最小包.md`
- `工作区/第N章_场景执行卡.md`

禁止打开或读取本章规划／审计资料包，也不得重新读取完整主线、大纲、章节细纲、状态表、轻检规则或修正规则。正文最小包已经包含本章写作所需的最小事实。

不得在正文生成阶段联网查询、打开外部数据库或补充检索任何领域事实。涉及专业对象、规则、参数、历史事实或技术细节时，只能采用正文最小包“已核验专业事实”中的内容；正文最小包没有提供的精确事实不得自行查询、凭记忆补全或猜测。

如果环境支持独立子任务，让写作任务在独立上下文中完成；只向写作任务提供上述两个文件和本工作流。

## Skill 调用

显式调用 `$writing-serial-fiction mode=prose-writing`，只提供：

- 本章正文最小包；
- 本章场景执行卡。

章节标题和总字数目标从正文最小包读取，精确结尾从场景执行卡读取；不得把标题、字数或停止条件拆成额外语义输入。

返回处理：

- Skill 无法加载或调用失败时，不得保存初稿，不得进入轻检；将当前阶段恢复为 `等待确认执行卡`，汇报失败原因后停止。不得绕过 Skill 自行生成正文。
- 返回以 `INPUT_ERROR:` 开头的一行时，不得保存为初稿，不得进入轻检；将当前阶段恢复为 `等待确认执行卡`，汇报缺失或无效字段后停止。
- 返回单行 `BLOCKED:` 时，不得保存为初稿，不得进入轻检；将当前阶段设置为 `阻塞冲突`，回填阻塞原因后停止。
- 成功输出必须只有指定的 Markdown 一级标题和一版小说正文。出现计划、自检、诊断、状态、第二版正文或停止点之后的续写时，属于输出形状检查未通过。输出形状检查未通过时，将当前阶段恢复为 `等待确认执行卡`，不得保存初稿，不得进入轻检，并汇报不合格项后停止。

## 写作优先级

1. 正文最小包中的决策相关状态、静默禁区和已核验专业事实；
2. 场景执行卡中的固定事件、结果和结尾落点；
3. 场景执行卡的展开顺序；
4. 正文最小包中的视角偏压和人物声纹。

两份输入中的硬事实无法同时成立时，只能按 `BLOCKED:` 分支停止，不得打开规划／审计资料包寻找第三套解释。

## 正文要求

- 正文总字数只服从正文最小包中的“目标字数”；3000～5000 字仅作为合法范围校验边界，不作为独立目标，不得另设更窄目标区间。
- 第一行必须输出 Markdown 一级标题，固定格式为：`# 第N章 章名`；章号和章名必须与正文最小包中的“章号／章名”一致。
- 标题后空一行，再直接开始小说正文。
- 按执行卡顺序完成 2～4 个场景，但不得照抄执行卡的规划措辞。
- 通过动作、对话、人物感受和会影响判断的环境细节写具体。
- 同一事实或边界由最有力的一处动作、对白或后果证明；已经表现清楚的信息不再换句解释。
- 多个小事件若只维持同一现状或证明同一规则，完整展开一处，其余合并压缩。
- 重要人物的对白必须依据目标、关系和受压反应形成差异；允许短答、回避、打断和不回答，不让所有人说完整分析或合同式台词。
- 不用无关回忆、重复心理、景物堆积、免责声明或解释性总结填充篇幅。
- 除非细纲明确要求，不新增重要人物、支线、核心设定、幕后原因、长期伏笔或额外视角。
- 普通过场人物不获得姓名、背景故事或后续任务。
- 不把小冲突升级为主线级事件。
- 输出前只进行一次静默去机械化删改：删除重复解释、合并同功能场面、缩短政策式对白、清除规划语言；不得生成第二版或开启多轮润色。
- 到达执行卡规定的结尾落点后立即停止。
- 不续写下一章。
- 不输出计划、自检、状态表、质量评价或修改建议。

## 输出

只有 Skill 成功输出通过上述形状检查后，正文才保存为：`工作区/第N章_初稿.md`

轻检通过前，不得创建或覆盖 `正文/第N章.md`。

保存成功后更新 `工作区/当前任务.md`：

- 当前阶段：`等待轻检`；
- 正文已生成：是；
- 初稿路径：实际路径。

然后返回控制器，由控制器读取并执行 `工作流/03_轻检.md`。正文写作任务本身不得进行轻检。
