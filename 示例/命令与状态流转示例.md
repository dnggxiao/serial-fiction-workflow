# 命令与状态流转示例

以下示例不包含具体小说内容，只演示第127章的操作。

只有当前阶段为 `空闲`，或第126章已经 `本章完成`、状态表已更新且第127章是合法下一章时，才能执行准备命令。

## 1. 准备章节

用户：

```text
准备第127章
```

预期结果：

- 创建 `工作区/第127章_资料包.md`；
- 创建 `工作区/第127章_正文最小包.md`；
- 创建 `工作区/第127章_场景执行卡.md`；
- 当前阶段=`等待确认执行卡`；
- 不存在第127章初稿或正式正文。

## 2. 作者确认

作者只检查：

- 是否新增重要事件；
- 是否改变细纲结果；
- 是否提前揭示后续；
- 结尾落点是否正确。

## 3. 生成正文

用户：

```text
确认执行卡，生成正文
```

预期内部顺序：

1. 只读取正文最小包和执行卡，创建 `工作区/第127章_初稿.md`；
2. 创建 `工作区/第127章_轻检报告.md`；
3. 根据轻检结论分支。

### 通过

- 创建 `正文/第127章.md`；
- 更新 `02_连续状态表.md`；
- 当前阶段=`本章完成`。

### 局部问题

- 初稿保留在工作区；
- 不创建正式正文；
- 不更新状态表；
- 当前阶段=`等待局部修正`。

用户可以输入：

```text
开始修正
```

系统最多修正一次并重新轻检一次。

重新轻检通过时，系统创建正式正文、更新状态表并进入 `本章完成`。重新轻检仍未通过时，无论结论类型如何，系统都进入 `等待作者决定`，不创建正式正文、不更新状态表，也不再开放 `开始修正`。

### 场景或整章问题

- 不自动重写；
- 当前阶段=`等待作者决定`；
- 用户根据报告决定是否发送 `确认重写场景` 或 `确认整章重写`。

只有修正次数为0时可以确认重写。重写后修正次数变为1；若重新轻检仍未通过，系统继续停在 `等待作者决定`，不生成正式正文、不更新状态表，也不再开放任何自动修正。

## 4. 下一章

第127章通过后，用户：

```text
准备下一章
```

预期：自动准备第128章规划／审计资料包、正文最小包和执行卡。
