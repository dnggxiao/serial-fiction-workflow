# 目标电脑安装验收

安装验收必须先于任何小说资料转换。

## 第一层：压缩包与清单

先把三个ZIP和 `SHA256SUMS-v*.txt` 放在同一目录。在通用包解压后的根目录运行：

```powershell
python tools/verify_release.py --release-dir <发布文件所在目录>
```

只有输出 `RELEASE_INTEGRITY_OK=3` 才能继续。该命令会同时校验外部SHA-256、三个ZIP结构、内部清单、重复路径和越界路径。

1. 核对收到的ZIP文件名和外部SHA-256。
2. 解压通用包到全新目录。
3. 校验根目录 `MANIFEST.sha256` 中的每一项。
4. 解压小说专用配置包到同一项目。
5. 校验专用配置目录内的 `MANIFEST.sha256`。

清单不一致时停止，不转换资料。

## 第二层：结构与Skill

在项目根目录运行：

```powershell
python -m unittest tests/skill-evals/test_skill_structure.py tests/skill-evals/test_workflow_skill_integration.py tests/skill-evals/test_v110_quality_guardrails.py tests/skill-evals/test_v120_naturalness_guardrails.py tests/skill-evals/test_v130_input_contract.py tests/skill-evals/test_v130_execution_card_guardrails.py tests/skill-evals/test_v130_prose_guardrails.py tests/skill-evals/test_v130_lightcheck_guardrails.py tests/test_portable_package.py -v
python tests/skill-evals/test_execution_card_contract.py --self-test
```

还必须确认：

- 项目本地存在 `.agents/skills/writing-serial-fiction/SKILL.md`；
- Skill允许的三种模式完整，并包含自然叙事正反例参考；
- 工作流01、02调用Skill，工作流03、04不调用；正文只接收正文最小包和场景执行卡；
- 所有Markdown代码块闭合；
- 没有具体小说内容或打包电脑的绝对路径泄漏到通用部分。

任何一项失败时停止，不转换资料。

## 第三层：环境报告

记录操作系统、Codex环境、Python版本、通用包版本、专用配置版本、测试结果和失败证据。不得通过下载未知依赖来掩盖环境缺失。
