# v1.4.0 Skill 命名迁移

v1.4.0 将核心 Skill 从平台专用名称调整为通用中文连载名称。这是一次调用令牌和目录路径的兼容性变更，不改变三个运行模式及其输入输出契约。

## 必须替换

| v1.3.1 及更早版本 | v1.4.0 起 |
| --- | --- |
| `$writing-fanqie-serial-fiction` | `$writing-serial-fiction` |
| `.agents/skills/writing-fanqie-serial-fiction/` | `.agents/skills/writing-serial-fiction/` |
| `references/fanqie-official-methods.md` | `references/fanqie-cn-profile.md` |

## 行为说明

- `chapter-planning`、`prose-writing` 和 `readonly-diagnosis` 的模式名称保持不变。
- 番茄写作资料保留为可选 profile，默认不加载。
- 只有明确要求番茄中文网文写作参考或方法出处时，才读取 `references/fanqie-cn-profile.md`。
- 不要同时保留新旧两个 Skill 目录，否则调用方可能加载到过期版本。
