# Changelog

All notable changes to this project are documented here.

## v1.6.0 — Official GitHub release package

### Added

- Complete GitHub repository source with `.agents`, `.github`, and `.gitignore`.
- Executable GitHub Actions release-check workflow.
- Chinese first-upload guide and repository-settings guide.
- `CONTRIBUTING.md`, `ROADMAP.md`, and v1.6.0 release notes.
- Standalone `skill.zip`, versioned Skill package, portable Codex workflow package, and SHA-256 checksums.

### Changed

- Unified all current release metadata to `1.6.0` / `v1.6.0`.
- Expanded the README into a public project landing page and installation guide.
- Kept the Fanqie material as an optional, non-official platform profile.

### Fixed

- Removed Python caches and compiled bytecode from the repository package.
- Replaced the placeholder Actions file with a working CI workflow.
- Corrected the mismatch between repository package, VERSION, and Release Notes.
