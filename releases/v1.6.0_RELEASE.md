# serial-fiction-workflow v1.6.0

首个适合正式公开 GitHub 发布的统一版本。

## Highlights

- 受控型中文长篇连载章节工作流；
- 独立 `writing-serial-fiction` Skill；
- 章节规划、正文写作和只读诊断三种模式；
- 正文最小包、场景执行卡、独立轻检和状态保护；
- 原创两章级流程演示基础；
- 完整 MIT License、用户内容边界和第三方说明；
- GitHub Actions 自动测试；
- 首次网页上传和仓库发布教程。

## 下载哪个文件

| 文件 | 用途 |
| --- | --- |
| `skill.zip` | 在支持 Skills 的环境中安装独立 Skill |
| `writing-serial-fiction-v1.6.0.zip` | 带版本名的 Skill 归档，与 `skill.zip` 内容一致 |
| `codex-novel-workflow-portable-v1.6.0.zip` | 解压后直接作为 Codex 小说项目工作区 |
| `serial-fiction-workflow-v1.6.0-official.zip` | GitHub 仓库源码备份 |
| `SHA256SUMS-v1.6.0.txt` | 校验下载文件是否完整 |

## 快速开始

### 安装 Skill

上传 `skill.zip`，然后显式调用：

```text
$writing-serial-fiction mode=chapter-planning
```

可用模式：

- `chapter-planning`
- `prose-writing`
- `readonly-diagnosis`

### 使用完整工作流

1. 下载并解压 `codex-novel-workflow-portable-v1.6.0.zip`；
2. 用 Codex 打开解压目录；
3. 阅读 `README_迁移.md`；
4. 完成安装验收后再开始章节生产。
