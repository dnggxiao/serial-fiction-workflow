# Prose writing

## 输入

依次要求以下非空字段：

1. 本章正文最小包；
2. 本章场景执行卡。

本章正文最小包必须包含章号／章名、目标字数、开场接口、决策相关状态、静默禁区、
视角偏压与人物声纹、已核验专业事实；本章场景执行卡必须包含 2～4 个场景、固定
事件结果和结尾落点。任一内部要求缺失时，将对应父字段视为缺失，并按上述顺序返回：

`INPUT_ERROR: missing=<字段1>,<字段2>`

输入事实无法同时成立时，只返回一行：

`BLOCKED: <最短冲突说明>`

## 写作边界

只使用本次提供的正文最小包和场景执行卡。不要打开规划／审计资料包、长期资料、
历史章节、状态表、网站、百科或维基；不要补造未经提供的精确专业事实。

严格保留执行卡中的固定事件、结果、人物决定和结尾落点，以及正文最小包中的静默
禁区。手法只决定怎样呈现，不能改变发生什么。

正文最小包中的决策状态和禁区作为静默约束；除非它们在固定事件中产生可见后果，
不在正文中复述、解释或写成免责声明。执行卡是幕后施工图，不是正文措辞来源；不
得照抄其中的“目标、边界、状态变化、可行性、衔接方式”等规划语言。

## 场景推进

按执行卡的因果顺序写，但把卡片翻译成现场中的人、物和动作：

1. 从视角人物当下真正注意到的刺激和立即要做的事进入；
2. 让已有阻力或他人反应打断、延缓或改变动作；
3. 写出选择造成的外部结果，以及资料已给的代价或状态变化；
4. 用未完成动作、新压力、被迫选择或可见后果启动下一场，不用旁白总结来转场。

## 自然叙事规则

- **最低充分证据。** 对影响选择的关键判断，保留足以支持当场行动的最小充分证据组。后续证据只有在提高证据等级、形成反证、改变置信度、触发新动作或产生新代价时保留；否则合并。诊断、验货、救援和安全操作所需的“观察—测量—功能测试—结果”可以完整保留。
- **限知允许主观。** 限知限制信息来源，不限制人物主观经验。可以写视角人物的欲望、厌烦、偏见、工作假设、诱惑和误判；叙述者不得把未亲见的幕后事实、精确技术结论或他人动机写成客观真相。
- **未变化状态默认静默。** 正文只呈现当前选择所需的基线、实际变化和会改变安全、成本或结果的读数。不得为证明守恒逐项写“仍为、未变、没有新增”，也不得写成“其余数值未变”。
- **推进节点不是段落。** 推进节点是因果检查点，不是段落、句数或镜头配额。相邻节点可以在同一动作链中完成；安全关键或顺序依赖的技术步骤仍须逐步可辨。
- **对白允许不完整。** 让人物回应对方刚说或刚做的事，并依据已给身份、目标、知识和关系形成不同语气。允许打断、回避、反问、短答、不回答和边做边说；避免所有人都使用完整分析、标准定义或合同式台词。
- **不要替人物把道理说满。** 当一个动作、停顿、收回工具或没有启动的发动机已经表达态度时，让场景继续。不是每个问题都要当场得到完整答案，也不是每次分歧都要形成清楚共识。
- **技术谨慎只说到必要处。** 需要区分亲见、他人陈述与推断时，使用一次准确限定即可；随后写会影响选择的证据或后果。避免在相邻段落连续使用“只能说明”“不能证明”“不等于”“并不代表”等免责声明句式。
- **旁白不做课后总结。** 重要结果出现后，先写在场人物的即时感知、动作或关系反馈。除非能增加尚未呈现的信息，不在每次交锋后概括“这说明了什么”。
- **细节必须参与判断。** 环境、身体和物件细节只取视角人物当下会注意、会误判或会据此行动的部分；不使用与选择无关的晨光、灰尘、呼吸和握拳作为通用装饰。
- **专业过程只留转折点。** 检查、交易或操作只展开会改变风险、选择、代价或结果的节点，不写教程、字段清单或完整合同流程。
- **句式服从现场。** 不追求整齐对称的“不是A而是B”“既不A也不B”“昨晚能A不等于今天能B”连续出现。强对照句只在真正承担转折或结尾时使用，周围句子改用动作、感知或直接陈述。
- **章末不做台账回收。** 固定结尾前后不得集中复述资源、关系、争议、身份、未知项和待办。精确抵达固定结尾落点，只保留完成结尾镜头所需的一项物件、读数、动作或选择。

不要强制安排反转、爽点、短句、否定句或身体反应的固定数量。安静章节也可以只
改变关系、信息、资源、认知或决定，但这种变化必须通过现场可观察的差异出现。

## 输出前的一次静默去机械化

正文写完后、输出前，只做一轮快速删改，不输出过程，也不进行第二轮重写：

1. 删除紧跟在动作或对白之后、仅仅换词复述同一意思的句段；
2. 合并连续证明同一状态或规则的平行小场面；
3. 把过长的政策式说明缩成角色会说的话，或改为停手、收物、转身、迟疑等可见反应；
4. 比较重要人物的对白，若互换说话人仍完全成立，就依据已给目标和关系改出差异；
5. 删除从执行卡泄漏进正文的课程术语、管理术语和验收语言；
6. 保留固定事件、连续性和结尾，不顺便增加情节或进行全文华丽化。

## 输出

只输出：

```markdown
# <章节标题>

<小说正文>
```

不要输出计划、方法说明、检查清单、诊断、修改建议、台账、状态摘要或文件操作。
完成上述单次静默删改后立即停止，不自行轻检、修正或生成第二版正文。
