# 手法选择器

本文件的选择流程与映射属于 `[Skill归纳]`。只在 `chapter-planning` 已完成字段校验且不存在硬冲突后使用。

## 输入边界

只使用调用方已经提取并明确提供的本章事实：

- 章节阶段与本章功能；
- 读者本章等待的结果；
- 本章主要状态变化；
- 主要场景类型；
- 情绪变化；
- 固定结尾落点；
- 禁止改变的事项。

未提供的信息不补查、不猜测。不得新增事件、结果、人物、地点、设定、支线或长期伏笔，也不得因为题材或类型惯例强行采用某种手法。

## 选择步骤

1. 先锁定必须发生的事件、固定结果、结尾落点与禁区；所有手法都服从这些事实。
2. 以最直接促成固定结果和主要状态变化的本章功能为主功能。多个功能同等重要时，按输入顺序确定主功能，同时完整保留全部固定事件。
3. 先判断固定事件是否已经足以清楚推进；足够时记录“无需额外手法”，不为使用技巧而使用技巧。需要额外手法时，只选择一个主要手法，用动词开头的一句话说明如何写，不只给出术语名称。
4. 只有输入明确承担第二种独立功能，且该功能可依附同一批固定事件完成时，才选择一个辅助手法；否则省略。不得选择第二个以上的辅助手法。“一主一辅”只是选择记录上限，不是正文技巧数量要求。
5. 若手法会改变固定事实，舍弃该手法，改选能服务原事实的动作。普通章节具有结尾并不自动构成“章末钩子”辅助手法。
6. 执行“一项意思只证明一次”：若多个固定事件都说明同一边界、同一风险或同一现状，只选一处完整戏剧化，其他内容压缩，不用多个人物轮流解释。
7. 把选择转换为可写入执行卡的具体动作和可观察结果。手法名称、课程术语和写作目的只留在内部选择记录，不进入卡片措辞。

## 通用功能映射

| 本章主功能 | 可选主要手法 | 正向落卡动作与可观察结果 |
| --- | --- | --- |
| 开篇／新阶段开启 | 建立眼前问题与核心承诺 | 仅在固定事件允许时，从已给连续状态中的具体差异、矛盾或未解决问题起步，明确人物眼前要做什么，让题材核心尽早运作并完成本章可达的首个可见微结果。 |
| 压力升级 | 加重既有时限、资源约束或阻碍 | 让输入中已经存在的压力产生新反馈，迫使人物改动作、换顺序或支付更高代价，不靠旁白宣布“压力增加”。 |
| 收益兑现 | 呈现付出后的可见结果及影响 | 让固定结果改变资源、位置、关系、能力、认知或控制权；优先以在场人物的即时动作承接，不追加同义解释。 |
| 交易／谈判 | 推动目标碰撞、筹码变化与成交后果 | 使用已给人物、目标、利益和筹码，让阻力、拒绝或代价来自各自利益。只完整展开最关键的一次交锋，平行归属问题压缩处理。 |
| 调查／悬念 | 缩小信息缺口并给出下一验证动作 | 只用已给线索完成部分验证，让读者得到部分答案，并把衔接落到已给的下一动作或固定结尾。准确限定只说一次，随后用证据推进。 |
| 关系推进 | 用行动证明态度并形成新边界 | 通过已有行为、选择或回应呈现关系变化，使新距离、责任或边界可被观察；不让人物替旁白总结关系含义。 |
| 安静过渡 | 用日常行动承载状态变化 | 在已有事件中让资源、关系、信息、位置或风险至少一项发生可辨认变化。同功能日常片段合并，避免逐项盘点。 |
| 章末钩子 | 落到具体异常、消息、选择或已启动动作 | 仅在固定结尾落点已经包含钩子时，精确抵达该落点并留下可执行接口；不追加空泛危险预告，也不在前文完整重复同一落点。 |

## 选择结果形状

只形成以下选择记录，供规划器转写进执行卡：

```text
主要手法：<一条绑定固定事件与结果的正向动作>
辅助手法：<一条依附同一批事实的正向动作，仅选中时出现>
落卡证据：<外部结果或状态变化，以及它如何形成下一动作接口>
```

不得把选择记录扩展为剧情提案、正文、诊断或修改意见。本文件不承担文件写入、工作流状态更新、资料巡视、轻检、修订或重写职责。
