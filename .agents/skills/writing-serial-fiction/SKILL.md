# Writing Serial Fiction

Use this workflow to keep author control over long-form fiction projects.

Core flow:

1. Prepare chapter materials.
2. Create scene execution cards.
3. Generate prose from approved context.
4. Run quality checks.
5. Update continuity state only after confirmation.

Do not invent facts outside approved project materials.
Do not replace author decisions with automatic changes.
