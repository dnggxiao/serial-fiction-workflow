# 通用小说工作流迁移包 v1.6.0

本包提供通用 Agent、工作流、Skill、空白长期资料模板、演示项目和验收工具，不包含作者的私人小说正文或具体小说状态。

## 安装顺序

1. 校验下载文件的 SHA-256。
2. 解压 `codex-novel-workflow-portable-v1.6.0.zip` 到一个全新目录。
3. 将解压后的 `codex-novel-workflow-portable` 目录作为 Codex 工作目录。
4. 先执行 `迁移/02_目标电脑安装验收.md`。
5. 安装验收通过后，加载对应小说的独立迁移配置。
6. 转换五份长期资料并生成验收报告。
7. 验收通过前不得准备章节或生成正文。

## 职责边界

- `AGENTS.md` 和 `工作流/` 负责命令路由、状态流转和文件保护。
- `writing-serial-fiction` 只负责章节规划、正文表现和独立只读诊断；正文只接收正文最小包与场景执行卡。
- 番茄写作资料位于可选 profile，默认不加载，也不构成平台认证或效果承诺。
- 五份长期资料负责小说事实、方向、细纲和文风；写作规则卡应只保存少量作者认可的短文风锚点和人物声纹。
- 小说专属路径、正史边界和来源映射必须放在独立迁移配置中。

## 输入边界

准备阶段生成规划／审计资料包、正文最小包和场景执行卡；正文不得读取规划／审计资料包。执行卡使用篇幅权重与视角偏压；轻检第七类只在叙事自证过度或状态表渗漏达到高阈值时拦截。
